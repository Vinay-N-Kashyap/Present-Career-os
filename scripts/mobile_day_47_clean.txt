Concept Invariant &amp; Guardrail Mobile apps cannot load 100,000 rows into JavaScript memory. WatermelonDB lazy-loads only the active records on demand, enabling snappy performance on multi-million row datasets. Failure Mode: Loading entire database tables into a single JavaScript array: JSON memory overhead causes severe garbage collection pauses and out-of-memory crashes.
