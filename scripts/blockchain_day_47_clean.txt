Understand the 'Optimistic' assumption: the sequencer batches thousands of transactions off-chain and posts the resulting State Root to Ethereum Layer 1, ASSUMING the state transition is valid without proving it upfront! If the state is assumed valid, how is security maintained? Enter Fault Proofs (Fraud Proofs) and the 7-Day Challenge Window: any honest verifier can challenge an invalid state root within 7 days. Deconstruct the Interactive Bisection Dispute Game (Arbitrum Nitro / Cannon): instead of re-executing an entire block on L1 (which exceeds block gas limits!), the challenger and defender play an on-chain binary search bisection game to narrow the disagreement down to a SINGLE EVM INSTRUCTION, executed on-chain via an EVM-in-EVM micro-interpreter (One-Step Prover)! Invariant: 1-of-N Honesty Invariant: An Optimistic Rollup requires only a single honest observer in the entire world to monitor state roots and submit a fraud proof during the 7-day challenge window to reverse an invalid state transition and slash the malicious sequencer. ⚠️ Failure Mode & tryIt Bug: Failure: Allowing immediate cross-chain withdrawals from an Optimistic Rollup to L1 without waiting for the 7-day challenge window; a malicious sequencer posts a fraudulent state root giving themselves $100M, withdraws immediately on L1, and absconds before challengers can submit a fraud proof. tryIt Friction: Construct an Interactive Bisection Dispute Game in TypeScript: simulate two parties disagreeing on the state after executing 1,024 EVM instructions; execute a log2(1024) = 10-step binary search bisection; pinpoint the exact instruction index where outputs diverge; execute a single-instruction One-Step Prover on-chain; and slash the dishonest party's deposit. 🪜 3-Tier Socratic Hint Ladder: [1.
