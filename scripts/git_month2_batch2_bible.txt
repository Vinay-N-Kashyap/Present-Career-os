          <span style="color: #c2410c; font-weight: 600;">Invariant:</span> <code>LFS Pointer Grammar & Smudge/Clean Invariant: In the Git repository, an LFS-tracked file is strictly a 3-line text pointer: $\text{version} + \text{oid sha256} + \text{size}$. The Clean filter intercepts files on stage/commit and uploads raw binaries to LFS storage; the Smudge filter downloads and hydrates raw binaries on checkout.</code>
